# Descubre con Dan - Portal Turístico 🌴🚀

Bienvenido al repositorio del sitio web **Descubre con Dan**, un portal turístico interactivo desarrollado para la **Guía de Laboratorio 4**.

## 📌 Páginas del Proyecto
- **Inicio (`index.html`):** Presentación principal con banner panorámico y accesos directos a los 6 destinos destacados.
- **Destinos (`informacion.html`):** Guías detalladas de cada región con recomendaciones de viaje.
- **Galería (`galeria.html`):** Selección fotográfica y contenido multimedia.
- **Itinerarios (`tabla.html`):** Tabla de tarifas nacionales según temporada alta y baja.
- **Contacto (`contacto.html`):** Formulario con validación en JavaScript para consultas e interés de viajes.

## 🛠️ Tecnologías Utilizadas
- **HTML5** (Estructura semántica)
- **CSS3 & Bootstrap 5.3** (Diseño responsivo y variables de estilo)
- **JavaScript ES6** (Validación dinámica de formularios)
